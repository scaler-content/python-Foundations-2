What this post-read covers

Arithmetic, comparison, logical, and assignment operators; the difference between = and ==; and operator precedence — the order Python follows when an expression mixes several operators.

01 · operators, the idea

What can we actually do with data?

Storing data in a variable is only the beginning. To add two numbers, check if someone's old enough, or combine two conditions, we need operators — a symbol or keyword that tells Python to perform an operation.

Python groups them into six families: arithmetic, comparison, logical, assignment, membership, and identity. This post-read walks through arithmetic, comparison, logical, assignment, and precedence in the same order we covered them in class.

💬 a / b and a // b are usually where guesses split first — regular division keeps the decimal, floor division throws it away.

Analogy — floor & modulus Think of 10 // 3 as "how many full groups of 3 fit inside 10?" — the answer is 3 groups. 10 % 3 is "what's left over after making those groups?" — 1.

10 lands past the 3rd multiple of 3. 10 // 3 is the tick you land on (3); 10 % 3 is the leftover red gap (1).

Handy use number % 2 equal to 0 means the number is even — this is the most common real use of modulus you'll see early on.

04 · = vs ==

They look almost identical. Are they?

age = 20 and age == 20 — same job, or different job?

💬 Different jobs. A single = is assignment — age = 20 means "put 20 into age." Two equal signs, ==, is comparison — age == 20 means "is age equal to 20?"

= → assign, == → compare. Mixing these up is one of the most common beginner mistakes — worth a second look every time you write a condition.

07 · operator precedence

What happens when an expression has several operators?

result = 10 + 5 * 2 — does Python do 10+5 first (→ 30), or 5*2 first (→ 20)?

result = 10 + 5 * 2
print(result)

20

💬 Multiplication happens before addition: 5 * 2 = 10, then 10 + 10 = 20. This ordering is called operator precedence — higher-priority operations run first.

The order this course uses, highest priority first:

2Exponentiation **
3Multiplication * / // %

Try one more, on your own first:

2 + 3 ** 2

Parentheses override all of this — they tell Python exactly what to calculate first:

print(10 + 5 * 2)     # 20
print((10 + 5) * 2)   # 30
✅ Takeaway When an expression gets complicated, parentheses aren't just useful for Python — they make your code easier for humans to read too.
08 · putting it together

Both classes, one program

score = int(input("Enter your score: "))

passed = score >= 40
excellent = score >= 90

print("Passed:", passed)
print("Excellent:", excellent)

Notice everything at work here: input() to get data, int() to convert it, a variable to store it, >= to compare it, Booleans to hold the result, and print() to show it. This is how the pieces from both classes start working together.
